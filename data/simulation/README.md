# Sabah simulation road snapshot

`sabah-roads.json.gz` is an OpenStreetMap Overpass JSON extract, included locally so playback and routing do not depend on a public routing service. The source timestamp is **2026-09-20T10:39:06Z**, and the requested bounds are west 115.65°, south 4.95°, east 116.70°, north 6.40°. This covers the real Kota Kinabalu crew depot and maintenance destinations around Keningau/Sook. It is a current map snapshot, not a reconstruction of July 2024 access.

Source: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), licensed under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/). Downloaded through the [Overpass API](https://maps.mail.ru/osm/tools/overpass/api/interpreter). Exact `source_query`, `source_url`, `query_bounds`, OSM copyright and timestamp are retained inside the archive. Highway ways, vehicle turn restrictions, barrier nodes and mapped rivers/streams/canals are included. There are no generated road coordinates.

`scenario_blocked_edge_ids` closes the mapped **Bulatan Capitol** roundabout (OSM way `117168871`, segments 0–24). These 25 short segments represent one authored road closure, not 25 observed incidents. The simulation excludes them from 24–88 seconds, including the reopening review. A normal route from the actual depot to `MY_N10125233295` is 6.642 km; the closure produces a 9.752 km mapped detour in this snapshot. Neither the closure nor traversability is a live observation.

The API honors permitted vehicle access, one-way travel, supported turn restrictions and requested closed segments. It excludes restricted/conditional roads and unsupported turn restrictions conservatively. It snaps endpoints to a permitted mapped road node within 300 m; it does not move an endpoint to a farther connected road to manufacture a route. Depot connectors and final site access remain unverified. Road-class speeds produce estimated durations, not measured traffic times. Missing/disconnected paths return no geometry. Mapped rivers are geographic context; animated river levels are illustrative scenario inputs.

An optional per-leg `sequence_group` identifies an ordered crew/day dispatch. Its first `from` sets the actual departure point. A routed stop advances the next departure to its returned road node; an unreachable stop is deferred and leaves that departure unchanged. Later planned `from` values in the same group are ignored, so an inaccessible site cannot become a fictional starting position. Ungrouped legs remain independent. This read-only assessment does not modify the saved optimizer schedule.

To refresh, replay the saved `source_query` against the saved endpoint, retain `query_bounds` and the authored closure metadata, and validate every closure edge against the new extract before replacing this asset. A road edit can renumber segment indexes, so a refresh requires reviewing the closure geography and the positive-detour test again. Runtime playback never refreshes the snapshot or makes external routing calls.
